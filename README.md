# Memomate

메모, 할 일, 캘린더를 한곳에 모은 나만의 메모장 웹페이지예요.
설치나 로그인 없이 브라우저만 있으면 쓸 수 있어요. (현재 1단계: AI 없는 기본 기능)

## 기능

- **메모**: 제목과 내용을 쓰고, 수정하고, 삭제해요. 작성·수정 시간이 표시돼요.
- **할 일**: 추가, 체크(완료 표시), 삭제. 마감일은 선택 사항이에요.
- **캘린더**: 월 달력에서 날짜를 누르면 그날의 일정, 마감인 할 일, 그날 쓴 메모를 한 화면에서 볼 수 있어요.
- **오늘 화면**: 오늘 일정, 오늘 할 일(지난 마감 포함), 최근 메모를 한눈에 보여 줘요.
- **자동 저장**: 내용은 내 브라우저에 저장돼서 새로고침해도 남아 있어요.

## 실행 방법 (Windows)

1. 이 저장소의 파일을 모두 한 폴더에 내려받아요. (Code 버튼 > Download ZIP 후 압축 풀기)
2. **start.bat**을 더블클릭해요. 작은 서버 창이 최소화돼서 열리고, 잠시 뒤 브라우저에 메모장이 떠요.
3. 브라우저에 메모장이 안 뜨면 주소창에 http://localhost:5000 을 입력해요.
4. 다 쓰고 나면 작업 표시줄의 Memomate-Server 창을 닫아서 서버를 꺼요.

서버 없이 쓰고 싶다면 **index.html**을 더블클릭해서 열어도 돼요.

## 파일 설명

| 파일 | 역할 |
|---|---|
| index.html | 화면의 뼈대 |
| style.css | 디자인 (맨 위 색상 변수만 바꾸면 분위기가 바뀌어요) |
| app.js | 모든 기능과 저장 코드 |
| serve.ps1 | 이 폴더를 localhost:5000으로 보여 주는 작은 서버 (Windows PowerShell) |
| start.bat | 서버를 켜고 브라우저를 여는 실행 파일 |

## 알아 둘 점

- 데이터는 **쓰고 있는 브라우저 안에만** 저장돼요. 다른 컴퓨터나 다른 브라우저에서는 보이지 않고, 브라우저의 사이트 데이터를 지우면 함께 사라져요.
- localhost 주소와 127.0.0.1 주소, 그리고 파일을 직접 연 경우는 저장 공간이 서로 따로예요. 한 가지 방식으로만 쓰세요.
- 주민등록번호, 계좌번호, 비밀번호 같은 민감한 정보는 메모에 적지 마세요.
